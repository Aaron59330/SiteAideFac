# PostItBac

Site pour réviser le bac : on colle son cours, il est résumé en post-it numériques rangés par matière.
Tout fonctionne dans le navigateur (aucun serveur, aucun compte) : ouvrir `index.html`.

- Résumé automatique, mots-clés et dates surlignés, glossaire et fiche de synthèse
- Bibliothèque par matière, recherche, favoris, édition des post-it
- Répétition espacée : les post-it reviennent au bon moment
- Modes de révision : cartes, texte à trous, QCM (raccourcis clavier)
- Objectif du jour, série, XP / niveaux, badges, calendrier d'activité
- Dates d'examen avec compte à rebours et rythme conseillé
- Minuteur Pomodoro (focus)
- Import de fichiers .txt/.md, export Anki, impression PDF, sauvegarde / restauration JSON
