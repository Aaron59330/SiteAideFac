# PostItBac

Site pour réviser le bac : on colle son cours, il est résumé en post-it numériques, rangés par matière.

- Bibliothèque par matière (ajout, renommage, suppression)
- Résumé automatique (dans le navigateur, sans serveur ni compte)
- Mode révision en flashcards avec suivi « je sais / à revoir »
- Recherche, édition des post-it, copie, impression/PDF
- Sauvegarde / restauration en fichier JSON

Utilisation : ouvrir `index.html` (ou l'héberger tel quel, par ex. GitHub Pages).
